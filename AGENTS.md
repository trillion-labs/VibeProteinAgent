# Agent Instructions

For protein or VPA work, read [skills.md](skills.md) first.

Use normal conversation for open-ended protein discussion. When the user asks to
run, validate, rank, submit, report, inspect existing `job_`/`wf_`/`arun_`
state, or otherwise execute an end-to-end protein workflow, switch to the VPA
Protein Design Workflow Operating Protocol in `skills.md`. Reporting or
submission requests may resolve to direct status/report mode over existing
workspace state rather than a new planned workflow.
